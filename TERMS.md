# Fred Terms of Service

Effective November 9, 2026

Fred is a private Discord bot for two approved users in one server. It offers date ideas, conversation prompts, a shared list, mood check-ins, and a countdown.

## Using Fred

Use Fred in the configured server and follow [Discord's Terms of Service](https://discord.com/terms) and the server's rules. Submit only content you have permission to share. Avoid submitting passwords, payment details, or other information you would not want the other approved user or the operator to see. Do not use Fred to harass someone, interfere with the bot, or bypass access restrictions.

Both approved users can view the shared list and each other's latest check-in. See the [Fred Privacy Policy](PRIVACY.md) for what Fred stores and how to request deletion.

## Availability

Fred is a personal tool provided as available. The operator may change, pause, or retire it. Its suggestions and countdown are for casual planning. Keep a separate copy of information you need to retain.

## Questions

Send a Discord direct message to the server owner who runs Fred for help or questions about these terms.
